# M04 · Motor de planificación

**Propósito:** Generar y ajustar planes semanales personalizados.

**Alcance:** Generar plan (Edge Function), ver plan, cambiar una comida, razones de recomendación, bloquear comidas, fallback determinista, cocinar/omitir comidas.

**Pantallas:** Plan semanal, Sustituir comida.

**Datos (tablas/vistas):** `meal_plans`, `planned_meals`, `recommendation_reasons`, `ai_generations`.

**Contratos (RPC / Edge / Auth):** Edge Function `generate-plan`; RPC `eligible_recipes`, `mark_meal_cooked`, `undo_meal_cooked`.

**Reglas clave:** El LLM solo elige dentro de `eligible_recipes`; todo se revalida; plan nace en `draft`.

**Límites:** Cuota y latencia de LLM; sin sobras ni hogares.

- Ficha completa: `05-historias-de-usuario/E2-*.md` (ancla `#us-103`)

### US-117 · Generar plan de comidas semanal automático
- Backend: Edge Function `generate-plan` (contrato en 02-arquitectura/edge-functions.md): `eligible_recipes` → ranking → (LLM opcional para explicaciones) → INSERT en `meal_plans` y `planned_meals` con `reason_code`; trigger `planned_meals_validate`; `plan_budget_status` para el costo.
- Pantallas: Plan (generar), Inicio
- Notas/límites: Objetivo ≤5 s p95. Si el LLM falla o tarda, el plan se genera igual solo con reglas y ranking (degradación elegante). Registrar uso en `ai_generations` (solo service role). Plan máximo 14 días (check); sin traslape (`meal_plans_no_overlap`).
- Ficha completa: `05-historias-de-usuario/E2-*.md` (ancla `#us-117`)

### US-123 · Marcar una comida como cocinada
- Backend: RPC `mark_meal_cooked(planned_meal_id)` (descuenta despensa FIFO por vencimiento, sin negativos, informa faltantes) y `undo_meal_cooked(id)` (ventana 10 s).
- Pantallas: Receta (cocinar ahora) → selector de calificación
- Notas/límites: La app muestra el `shortfall` devuelto, no bloquea. Deshacer falla si ya se calificó.
- Ficha completa: `05-historias-de-usuario/E2-*.md` (ancla `#us-123`)

### US-129 · Cambiar una comida del plan por una alternativa

- Notas/límites: Solo comidas en estado `planned`. La lista de compras y el presupuesto se recalculan después del cambio.
- Ficha completa: `05-historias-de-usuario/E2-*.md` (ancla `#us-129`)
