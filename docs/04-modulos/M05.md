# M05 · Asistente IA

**Propósito:** Conversación que explica, propone cambios y cocina "con lo que tengo".

**Alcance:** Chat, sugerencias aplicables, preguntas sobre sustitutos y despensa.

**Pantallas:** Asistente.

**Datos (tablas/vistas):** `assistant_conversations`, `assistant_messages`, `ai_generations`.

**Contratos (RPC / Edge / Auth):** Edge Function `assistant-chat`; RPC `apply_assistant_suggestion`.

**Reglas clave:** Nunca aplica cambios por sí mismo; no da consejo médico; entrada tratada como no confiable.

**Límites:** Solo es-CO; historial limitado; sin voz.

### US-157 · Cambiar una comida mediante el asistente conversacional
- Backend: Edge Function `assistant-chat`; `assistant_conversations`/`assistant_messages` con `suggested_recipe_id` + `target_planned_meal_id`; RPC `apply_assistant_suggestion(message_id)`.
- Pantallas: Asistente
- Notas/límites: La sugerencia es un dato tipado, no texto libre. El usuario confirma; aplicar pasa por las MISMAS validaciones que un cambio manual.
- Ficha completa: `05-historias-de-usuario/E2-*.md` (ancla `#us-157`)
