# M09 · Notificaciones

**Propósito:** Recordatorios útiles y respetuosos.

**Alcance:** Registro de token push, preferencias, recordatorio de comida, alerta de vencimiento, resumen semanal.

**Pantallas:** Notificaciones (preferencias).

**Datos (tablas/vistas):** `notifications`, `push_devices`, `notification_preferences`.

**Contratos (RPC / Edge / Auth):** Edge Function `send-notifications` + pg_cron.

**Reglas clave:** Respetar preferencias; sin datos sensibles en el texto.

**Límites:** Solo push; sin email/SMS.
