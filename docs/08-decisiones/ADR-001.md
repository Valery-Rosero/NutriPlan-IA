# ADR-001 · Expo (React Native) + TypeScript estricto

**Estado:** Aceptada

## Contexto y decisión
App móvil multiplataforma con un solo código; EAS para builds y OTA.

## Alternativas consideradas
Flutter/nativo: más costo; descartado para MVP.

## Consecuencias
Equipo único en TS; límites de módulos nativos.
