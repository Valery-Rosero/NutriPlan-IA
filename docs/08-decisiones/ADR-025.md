# ADR-025 · Asistente con Gemini, sin datos de salud en el prompt

**Estado:** Aceptada (piloto)

## Contexto
F2 pide un asistente conversacional (US-157 cambiar una comida, US-160 armar algo solo con la despensa, US-173 respuestas rápidas). ADR-003 y ADR-004 ya fijan que el LLM solo propone, desde una Edge Function y con salida estructurada. El equipo tiene una API key de Google Gemini.

## Decisión
- **Proveedor:** Google Gemini por su API REST `generateContent`, con `responseSchema` (JSON tipado). El modelo se elige con el secreto `GEMINI_MODEL` (por defecto `gemini-2.5-flash`) para cambiarlo sin desplegar código.
- **La clave** vive solo como secreto de la Edge Function `assistant-chat` (`GEMINI_API_KEY`). Nunca en la app, el repositorio ni los logs.
- **Minimización de datos (Ley 1581):** el prompt NO lleva alergias, dietas ni datos de salud. La función pide las candidatas con el JWT de la persona (`cook_with_what_i_have`, que ya pasa por `eligible_recipes`), así que el filtro duro ocurre en SQL antes de llegar al modelo. Al modelo solo van: el mensaje, hasta 10 mensajes previos, y una lista de candidatas (id, título, minutos, % que tiene, lo que falta) más la comida destino si la hay.
- **El LLM elige, la BD dispone:** la respuesta `{ reply, recipe_id?, target_planned_meal_id? }` se valida con Zod; `recipe_id` debe estar entre las candidatas y la comida destino debe ser de la persona. Aplicar usa `apply_assistant_suggestion`, que revalida elegibilidad.
- **Sin modelo, igual responde:** si Gemini falla o excede el tiempo, la función responde con la mejor candidata determinista (cobertura de despensa) y lo marca `fallback: true`.
- **Cuota:** 30 mensajes por persona y día (contados en `ai_generations`).
- **Temas médicos:** el prompt de sistema obliga a no diagnosticar ni dar consejo médico; se responde con el aviso de salud.

## Alternativas consideradas
- Claude u OpenAI: válidos; se elige Gemini porque el equipo ya tiene la clave. Cambiar de proveedor solo toca el adaptador `llm.ts` de la función.
- Enviar el perfil completo al modelo para que "entienda" las alergias: descartado; las alergias se resuelven en SQL (ADR-003) y no salen de la base.

## Consecuencias
- **Capa gratuita vs. de pago:** en la capa gratuita de la API de Gemini, Google puede usar el contenido enviado para mejorar sus productos; con facturación activa, no. Desarrollo y pruebas internas pueden usar la gratuita; **con usuarios reales del piloto, la clave debe ser de un proyecto con facturación activa** (verificar los términos vigentes de Google antes del lanzamiento).
- La política de privacidad debe nombrar a Google como encargado fuera de Colombia (revisión legal pendiente).
- Latencia: el criterio de US-157 pide < 2 s; con un modelo flash suele cumplirse, pero depende de la red. El respaldo determinista cubre fallas.
