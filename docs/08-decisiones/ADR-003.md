# ADR-003 · El LLM propone, la BD dispone

**Estado:** Aceptada

## Contexto y decisión
Alergias/dietas son filtros duros en SQL (`eligible_recipes`); el LLM solo ordena dentro del conjunto y toda sugerencia se revalida.

## Alternativas consideradas
Confiar en prompts: inseguro.

## Consecuencias
Más lógica en SQL; calidad del plan depende del catálogo.
