# ADR-002 · Supabase como backend único

**Estado:** Aceptada

## Contexto y decisión
Postgres + Auth + Storage + Edge Functions + RLS reducen piezas; la lógica de negocio vive en SQL probado.

## Alternativas consideradas
Backend propio: más operación.

## Consecuencias
Dependencia del proveedor; mitigada con migraciones SQL portables.
