# ADR-004 · LLM solo desde Edge Functions con salida estructurada

**Estado:** Aceptada

## Contexto y decisión
Protege claves, controla cuota/costo y permite validar con Zod.

## Alternativas consideradas
Llamar al LLM desde la app: inseguro.

## Consecuencias
Latencia extra; necesidad de fallback determinista.
