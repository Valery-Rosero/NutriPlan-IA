# ADR-019 · Límite de intentos de inicio de sesión con los límites de Supabase + CAPTCHA

**Estado:** Aceptada (13-oct-2026).

## Contexto y decisión
US-104 pide bloquear 15 minutos tras 5 intentos fallidos. Supabase Auth no tiene bloqueo por cuenta, solo límites de tasa
por IP. Se usan esos límites y, si hay abuso, CAPTCHA (Cloudflare Turnstile o hCaptcha, soportados por Supabase Auth).
La app muestra un mensaje genérico tras varios intentos fallidos.

## Alternativas consideradas
Contador propio en una Edge Function que intermedie el login: duplica Auth y agrega riesgo.

## Consecuencias
El criterio de US-104 se cumple de forma equivalente (frena fuerza bruta), no literal. Documentado en la historia.
