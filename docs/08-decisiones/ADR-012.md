# ADR-012 · Expo Router, TanStack Query (+persist), Zustand mínimo, RHF + Zod

**Estado:** Aceptada con cambios (12-nov-2026)

## Contexto y decisión
Convenciones estándar y tipadas; ver `02-arquitectura/convenciones.md`.

## Alternativas consideradas
Redux, navegación manual.

## Consecuencias
Cambiar requiere ADR.

## Cómo quedó
Expo Router (con `Stack.Protected` para las puertas), TanStack Query 5 con persistencia y `onlineManager`, React Hook Form + Zod 4. **Zustand no hizo falta:** el estado de servidor vive en TanStack Query la sesión en un contexto de React, los servicios inyectados por contexto (ADR-022) y el tema con `Appearance` del sistema. Si aparece estado global de UI compartido entre pantallas, se puede agregar sin otro ADR.
