# ADR-018 · El plan se arma con reglas; el LLM no está en el camino crítico

**Estado:** Aceptada (13-oct-2026). Resuelve la contradicción C1 y C2 de `07-plan-de-construccion/plan-de-arranque.md`.

## Contexto y decisión
US-117 exige ≤5 s p95; un LLM no lo garantiza. `generate-plan` arma el plan con ranking determinista
(TypeScript + RPC): `eligible_recipes` → puntaje (despensa y vencimientos con `cook_with_what_i_have`/`recipe_pantry_match`,
variedad de proteína, cocinas favoritas, presupuesto, calificaciones) → `save_generated_plan` (una transacción).
El `reason_code` lo asigna la regla que más pesó (US-155: el motivo siempre es verdadero).
El LLM se usa solo en el asistente (F2) y, opcionalmente, para redactar explicaciones, con timeout de 4 s.

## Alternativas consideradas
LLM que elige las recetas: más lento, más caro y difícil de probar.

## Consecuencias
El plan funciona sin proveedor de IA y sin costo variable. El spike US-103 mide calidad y decide si el LLM agrega valor.
