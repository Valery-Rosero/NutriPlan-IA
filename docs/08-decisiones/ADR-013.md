# ADR-013 · Jest + RNTL + Maestro + pruebas SQL

**Estado:** Aceptada con cambios (12-nov-2026)

## Contexto y decisión
Pirámide de pruebas alineada con los criterios Dado/Cuando/Entonces.

## Alternativas consideradas
Detox.

## Consecuencias
Maestro es más simple, menos control fino.

## Cómo quedó
Jest + React Native Testing Library (app), pruebas SQL con Supabase local (`backend/supabase/tests/run_local.sh`), lógica de Edge Functions con Jest (`npm run test:functions`) y una **prueba de integración** del recorrido completo contra Supabase real (`npm run test:integration`), todas en CI. **Maestro no se adoptó:** la integración cubre el flujo de datos sin emulador, y lo que solo se ve en el teléfono (arranque, avisos, TalkBack, letra al 200 %) se prueba a mano con el APK. Retomar Maestro si las pruebas manuales se vuelven frecuentes.
