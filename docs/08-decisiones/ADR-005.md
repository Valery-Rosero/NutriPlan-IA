# ADR-005 · Modelo de datos 3FN, derivar en vez de almacenar

**Estado:** Aceptada

## Contexto y decisión
Alérgenos, dietas, nutrición por porción, picante y batch cooking se derivan por vistas; evita inconsistencias.

## Alternativas consideradas
Columnas desnormalizadas.

## Consecuencias
Consultas más complejas; vistas deben mantenerse.
